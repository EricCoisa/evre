# 🌍 Internacionalização (i18n)

Este template suporta múltiplos idiomas através do `nestjs-i18n`.

## 📋 Idiomas Suportados

- 🇧🇷 **pt-BR** (Português - Brasil) - Padrão
- 🇺🇸 **en** (English)

## 🔧 Como Usar

### 1. Selecionar Idioma via Query Parameter

```bash
GET /api/auth/me?lang=en
GET /api/auth/me?lang=pt-BR
```

### 2. Selecionar Idioma via Header

```bash
# Accept-Language
curl -H "Accept-Language: en" http://localhost:3000/api/auth/me

# Custom header (X-Language)
curl -H "X-Language: en" http://localhost:3000/api/auth/me
```

## 📁 Estrutura de Arquivos

```
src/i18n/
├── pt-BR/
│   ├── auth.json          # Mensagens de autenticação
│   ├── validation.json    # Mensagens de validação
│   ├── user.json          # Mensagens de usuário
│   └── common.json        # Mensagens comuns
└── en/
    ├── auth.json
    ├── validation.json
    ├── user.json
    └── common.json
```

## 🎯 Ordem de Prioridade dos Resolvers

1. **QueryResolver** (`?lang=en`) - Maior prioridade
2. **HeaderResolver** (`X-Language: en`)
3. **AcceptLanguageResolver** (`Accept-Language: en`)
4. **Fallback** (`pt-BR`) - Padrão

## ✍️ Como Adicionar Novas Traduções

### 1. Adicionar chave no arquivo JSON

**`src/i18n/pt-BR/user.json`**
```json
{
  "welcome": "Bem-vindo, {name}!"
}
```

**`src/i18n/en/user.json`**
```json
{
  "welcome": "Welcome, {name}!"
}
```

### 2. Usar no código

```typescript
// No Service
constructor(private i18n: I18nService) {}

getMessage(name: string) {
  return this.i18n.t('user.welcome', { args: { name } });
}
```

### 3. Usar em DTOs (validação)

```typescript
const UserSchema = z.object({
  name: z.string().min(1, 'validation.name.required'),
});
```

## 🌐 Adicionar Novo Idioma

### 1. Criar estrutura de arquivos

```bash
mkdir src/i18n/es
```

### 2. Copiar e traduzir arquivos

```
src/i18n/es/
├── auth.json
├── validation.json
├── user.json
└── common.json
```

### 3. Pronto! O i18n detecta automaticamente.

## 🔍 Interpolação de Variáveis

```json
{
  "greeting": "Olá, {name}! Você tem {count} mensagens."
}
```

```typescript
this.i18n.t('greeting', { 
  args: { name: 'João', count: 5 } 
});
// Resultado: "Olá, João! Você tem 5 mensagens."
```

## 📝 Exemplo Completo

### Endpoint com tradução

```typescript
@Get('profile')
async getProfile(@CurrentUser() user: AuthenticatedUser) {
  const userProfile = await this.usersService.findById(user.id);
  
  return {
    message: this.i18n.t('user.profile.title'),
    data: userProfile,
  };
}
```

### Request em Português

```bash
curl -H "X-Language: pt-BR" http://localhost:3000/api/user/profile
```

**Response:**
```json
{
  "message": "Perfil completo do usuário autenticado (busca no banco)",
  "data": { ... }
}
```

### Request em Inglês

```bash
curl -H "X-Language: en" http://localhost:3000/api/user/profile
```

**Response:**
```json
{
  "message": "Complete authenticated user profile (from database)",
  "data": { ... }
}
```

## ⚙️ Configuração

A configuração está em `src/app.module.ts`:

```typescript
I18nModule.forRoot({
  fallbackLanguage: 'pt-BR',
  loaderOptions: {
    path: path.join(__dirname, '/i18n/'),
    watch: true, // Hot reload em desenvolvimento
  },
  resolvers: [
    { use: QueryResolver, options: ['lang'] },
    AcceptLanguageResolver,
    new HeaderResolver(['x-language']),
  ],
})
```
